## 复现命令与启动条件

当前实现依赖相邻 `../Mr-Robot-Arm` 仓库，包含 `mr_robot/dual_arm.py`、`mr_robot_desktop/fused_pose.py` 和几何模型。可通过 `--pose-library` 指定其他路径。PC需要带Tk的Python、FFmpeg与以下依赖。

```powershell
python -m pip install -r requirements-pc.txt -r requirements-monitor.txt
python exploration_monitor.py --camera http://127.0.0.1:8768 --rotation 180 --pose-mode fused
```

相机服务已使用单一采集进程共享视频。需要重启时先确认旧进程退出，再使用对应完整DirectShow设备路径启动，`--reconnect` 会在采集退出后关闭旧采集并重建。

```powershell
python camera_server.py --port 8768 --device "完整夹爪相机设备路径" --fps 10 --width 1280 --reconnect
python camera_server.py --port 8769 --device "完整外部相机设备路径" --fps 15 --width 1280 --reconnect
```

完整演示采用已经核验的准备态启动。COM8板端REPL保留 `d` 对象，类型为 `DualArm`，已使能并保持绿臂1的307/287/297、绿臂2的307/307/307。观察臂已经使能、归零并移动至指令参考位X0 Y164 Z120，视觉确认停稳。其他串口控制器应关闭连接。

冷启动需要重新建立准备态。本次实际步骤包括中断原ArmConsole、关闭16路输出、配置PCA50 Hz、建立 `d` 并在相机核对当前姿态后使能。可复用相邻仓库 `docs/dual-arm-calibration-20261117.md` 的DualArm入口，将对象命名为 `d`。`enable` 会输出位置目标，当前物理姿态与路径须先核验。观察臂通过 `code/pc_session.py --port COM3` 执行M17、经现场确认路径的G28、逐段移至参考位并确认停稳。PC演示程序检查准备态，准备态缺失时暂停并报告。

```powershell
python embodied_demo.py --phase full --cycles 2 --output .runtime/demos/my-demo
```

拆分复测使用 `--phase single`、`--phase dance --cycles 2`、`--phase cruise --cruise-stage repeat`。输出目录应为每次新建的目录，分别保存report.json、poses.jsonl、事件、串口记录及双相机证据帧。

录像单独运行，复用已有流和原生窗口采集。它持续记录，控制程序独立运行。

```powershell
python experiment_recorder.py record --output .runtime/recordings/my-demo --camera http://127.0.0.1:8768 --external http://127.0.0.1:8769/stream.mjpg
```

完成动作后在录像目录创建STOP文件，等待录制进程结束。再导出与验证。

```powershell

python experiment_recorder.py export .runtime/recordings/my-demo --layout landscape
python experiment_recorder.py verify .runtime/recordings/my-demo
```

## 视觉方法与闭环边界

自动绿色分割定位两台前景，DoG圆形孔位候选和四孔几何进行初始化，有序孔位通过双向LK光流持续跟踪，PnP分支按时间连续性筛选，连杆长度约束补足可解释的骨架。遮挡时允许三孔解算，视觉不足时标记预测或丢失。UI使用同一源帧的检测结果，源帧过期显示原图与状态。

B/S为固定安装模型估计，E/TCP为板姿态加连杆约束估计，F_L/F_R为名义夹爪锚点。相机内参近似、畸变未拟合、第二台绝对参考角近似。物理关节轴心和独立测得的关节角字段均为未知。命令角度、插值和模型投影仅作为目标及先验。Q为未校准概率的质量分数。

每个机位拥有独立相机参考坐标。跨视角外参尚未完成统一验证，跨机位世界坐标闭环保留未知。换机位时清除跟踪状态并重新捕获。身份核验要求前后使用同一机位，换机位后须重做该项测试。

每段板端轨迹完成后，还需等待并比较间隔0.6秒的新鲜画面，绿色前景光流P90小于0.8像素且有效特征至少12个才登记停稳。控制器回复、软件轨迹结束、视觉停稳分别记录。低质量先等待重新捕获，必要时使用已验证路径移至Z125；异常停止新增动作。保持输出继续提供位置保持力。

## 实测调试记录

### 偏差与幅度修正

独立适配轮次位于 `.runtime/demos/dance-adaptation-20261117/report.json`。同一机位将幅度从10 counts缩至6 counts，命令模型与观测板孔投影差的P90从16.00 px降至12.06 px，两轮丢失和纯预测补点均为0。

留出的后续完整实机轮次位于 `.runtime/demos/full-repro-20261117`。再次触发幅度10至6的调整，相同指标从16.67 px降至14.57 px，下降约12.6%。该指标包含模型与参考角偏差，关节角精度仍待独立标定。

### 视角与间歇丢失

扩大巡航时，C点Z130曾在第二台底座动作后出现低质量。系统暂停后续绿臂动作，沿已验证路径移至Z125重新捕获。包含失败与恢复的223帧区间记录39个丢失样本、6个预测样本，Q的P10约0.28。

将重复巡航C点改为Z125，使用相同底座10-count与同步6-count动作复测，173帧中丢失与预测均为0，Q的P10约0.81。该轮观察臂巡航速度同时从5提高至7 mm/s，绿臂动作速度保持4°/s。

最后完整轮次里Z130也通过了测试，Z125的Q波动至约0.53。该结果支持采用质量门控和重新捕获，视角高度单一因素的因果关系仍待进一步控制变量验证。

### 多视角巡航

Y固定164 mm。第一阶段F5依次经过X−5/Z120、X0/Z125、参考位。第二阶段F5经过X−10/Z120、X0/Z130、参考位。第三阶段F7经过X−10/Z120、X0/Z125、参考位。逐阶段进行了新鲜双摄取图、停稳和已走路径的实物检查，保留短暂停留。第三阶段采用本次已经验证的范围和速度。
