## 本轮用户补充（覆盖上表对应未知项）

实际采用TB6600模块、XIAO ESP32S3系列主控，独立单轴验证，不研发综合板。拨码为16细分、3200脉冲/电机转，额定1.0A、峰值1.2A，均为用户提供，尚未现场测量或复核电机匹配。

|主控|GPIO|驱动器|
|---|---|---|
|D0|1|ENA+|
|D1|2|DIR+|
|D2|3|PUL+|
|GND|GND|ENA−、DIR−、PUL−均接GND，用户确认|

用户确认3.3V可驱动。TB6600模块具体厂家/版本仍未知，不能套用其他模块手册；不得尝试GPIO输出5V。GPIO3为启动配置相关引脚，复位期间电平及外部负载对启动的影响需现场核验。程序导入不配置引脚，但上电/复位期间的输出不能由Python保证；首次安装应关闭电机功率电源，核对静态信号及ENA后再上电。电机供电、线序、限位/编码器、每转毫米和安全余量仍未知。32脉冲只是软件硬上限（电机0.01转），不代表已知安全毫米行程；必须现场确认更小的实际额度、方向及净空。

依据：[Seeed官方引脚表](https://wiki.seeedstudio.com/xiao_esp32s3_getting_started/)；[MicroPython v1.26 RMT API](https://docs.micropython.org/en/v1.26.0/library/esp32.html)。本实现采用该API的clock_div=80（1us）、write_pulses与wait_done；当前板端固件版本/RMT能力未读取，必须先核验。不自动改用Python忙循环发脉冲。

### ENA极性已确认

用户现场确认：光耦导通=脱机释放，无阻尼；光耦截止（悬空或低电平）=使能锁轴。按当前负端共GND接法，GPIO1/D0低电平使能，高电平释放。bringup配置固定enable_level=0：创建时输出高电平释放；start输出低电平锁轴，stop与运动完成均保持低电平，deinit输出高电平释放。释放可能使负载自由运动，必须支撑负载。悬空/复位不能当作禁用，Python运行前的输出状态仍需硬件措施保证。

本轮用户已确认两个方向各6400脉冲安全，驱动v0.2.0将单次硬上限设为6400，累计硬上限12800；额度仍须显式传入。此前32脉冲上限及两脉冲测试属于历史验证记录。没有毫米传动参数，不将脉冲换算为实测行程；6400脉冲按用户3200脉冲/圈配置对应电机2圈。示例超时按请求脉冲数计算，不再沿用仅适合极短动作的固定2秒。

## 工业输入预留与维护来源

用户新增3只SN04-P（中位+双端限位）和1只HN3806-AB-600F 600线AB编码器。型号、线色、电压、输出类型及待定GPIO/电平转换见inventory.json和[sensor-inputs.md](sensor-inputs.md)。这些工业输出不得直连3.3V输入；软件预留接口不代表已安装或具备运动联锁。独立源以drivers/micropython/linear_stage子模块接入，固定版本见[source-lock.json](source-lock.json)；tools/sync_linear_stage.py仅同步板级配置/示例/说明，驱动不再复制。本轮无实机传感器测试。
