# RobotArm 浏览器运动仿真

运行 `python -B simulator/serve.py`，或双击项目根目录的 `start_simulator.cmd`，然后打开 http://127.0.0.1:8767/ 。页面使用已下载到本地的 Three.js 和真实 STL 零件，运行时无需联网。

## 使用

- 调整 XYZ 目标与进给速度，点击“预览移动”查看笛卡尔直线插补。
- 使用步长按钮微调目标，或拖动底座、大臂、肘部滑块查看关节姿态。
- 使用“夹爪开合”滑块、闭合和张开按钮控制照片重建夹爪。机械臂移动期间可以拖动夹爪滑块，查看同时运动的效果。
- 输入 G-code 后点击“检查轨迹”，再点击“播放程序”。支持暂停、继续、停止及 G-code 导出。
- 在“模型与参考范围”中调整连杆长度、工具偏移、肩轴离台面高度及参考运动范围。
- 摄像头按钮连接本机已有的 http://127.0.0.1:8766/stream.mjpg 。对应服务由根目录 `camera_server.py` 提供。

坐标原点为肩轴中心，+Y 为机械臂正前方，+X 为横向，+Z 向上。底座角度从 +Y 向 +X 为正。大臂仰角相对水平面，小臂绝对仰角等于大臂仰角加肘部相对角。平行四边形连杆保持末端支架水平。

默认参考姿态为 X0、Y174、Z120，大臂竖直、小臂水平。模型的关节中心从装配 STL 孔位取得，默认连杆长度为120 mm、120 mm，径向工具偏移为54 mm，取自上游 v0.81 的 `config.h`。肩轴离台面130.2 mm 根据原始 STL 装配坐标推导。

## ZCJD 夹爪装配

机械臂末端加载 `../mechanical/photo_reconstruction` 内的16件照片重建夹爪。独立夹爪页面和整机仿真共用模型加载及四连杆开合逻辑，齿轮反向同步转动，爪指保持平行。舵机壳体及安装槽沿底板横向布置，壳体长轴与底板长边垂直，输出轴与左齿轮同轴，方向依据163953安装照和用户说明。

夹爪根据安装近照 IMG_20261116_164451.jpg 装配。顶端横向翻边压在腕部支架上面，翻边底面位于支架顶面上方0.2 mm（显示间隙），竖板和爪指朝下，舵机朝向机械臂内侧。根据原腕部 STL 的前端面与顶面，夹爪板原点相对腕轴默认前伸34.2 mm、抬高4.2 mm。5 mm厚翻边的底面位于腕轴下方0.8 mm，支架顶面位于腕轴下方约1 mm。翻边后缘位于腕轴前方21.2 mm，避开原腕部凸台最前缘约21 mm；竖板后表面位于腕轴前方36.2 mm。可通过“夹爪安装前伸”和“夹爪安装 Z”校准。54 mm工具偏移仍确定指令参考点，夹持中心按安装变换独立计算。底板约8 mm厚、翻边约5 mm厚、支撑肋约6 mm宽、凸起约17 mm，翻边总伸出约21 mm，依据165449、165503、165541、165559及170225、170303、170535卷尺近照更新。安装配合采用照片与模型推算，实物尺寸仍需测量校准。

金色标记显示XYZ指令参考点，青色标记显示两指接触区的中心。侧栏同步显示爪口净开度和夹持中心XYZ。夹爪开合会使夹持中心沿竖直方向变化，参考姿态与70%开度下的夹持中心约为X0、Y164.7、Z47.1 mm。

## 支持的程序

G0/G1 使用绝对坐标。遗漏轴保留当前数值，F 为 mm/s，后续指令沿用上次 F。G4 S 使用秒。每段直线按不超过1 mm间距采样，检查几何可达性、前半工作区、参考底座与肘部角度以及Z范围。

G28 直接切换到参考姿态，实际限位开关搜索过程未建模。M3/M5 在同一条程序时间轴上连续播放夹爪闭合和打开，完整行程的预览时长为0.65秒，部分行程按开度差缩短。该时长为预览设定，实际舵机速度需校准。暂停、继续和停止同时作用于机械臂与夹爪程序。夹爪动画期间拖动滑块将切换到手动开度控制。

I/J 记录舵机角度目标，0–180°为预览输入范围，角度到夹爪开度的实际关系仍需标定。IO、电机使能和12V模式的M指令记录为时间轴事件。其他指令会明确报错。G-code 导出包含预览起点、夹爪起始开度、安装前伸与高度和几何参数，运行时应核对实机坐标与参数。

机械臂移动时间按恒定进给计算，参考固件的加减速曲线未重现。预览尚未建模整机碰撞、负载、皮带弹性、齿隙及电机失步。机械臂的电机、皮带和紧固件采用简化外形。夹爪尺寸根据照片重建，具体假设记录在 [夹爪建模说明](../mechanical/photo_reconstruction/README.md) 及参数文件中。

## 下载文件与来源

完整 STEP 装配在 `../mechanical/upstream/community_robot_arm/CAD Files/robot_arm.step`，全部 STL 位于同一 CAD Files 目录及其子目录。69个上游文件约45.7 MB。`../mechanical/upstream/community_robot_arm/manifest.json` 记录来源、固定提交版本、文件长度和SHA256校验值。`download_models.py` 可恢复下载，按Git blob哈希核对上游文件。

模型来自 [20sffactory / community_robot_arm](https://github.com/20sffactory/community_robot_arm)，基于 Florin Tobler 的 RobotArm，固定提交为 `6c2f57390f0186f47bb199f06c875dedf8de268f`。根据上游README，CAD及图形资料采用CC BY 4.0，固件采用GPL-3.0。上游固件仅作为尺寸及运动学参考保存在下载目录中。

Three.js 0.170.0及配套OrbitControls、STLLoader保存在 `vendor/`，采用MIT许可，许可原文位于 `vendor/LICENSE`。

## 验证

运行 `node simulator/check_math.mjs` 可验证正逆运动学往返、几何边界、直线路径、绝对坐标、参数校验和G-code语义。实际浏览器已验证STL加载、轨迹检查和示例播放。

运行 `node simulator/check_gripper.mjs` 可验证夹爪开合端点、齿轮反向、平行四连杆、不同底座角度下的安装变换、夹持中心坐标，以及包含M3/M5的联合G-code时间轴。浏览器已验证整机移动时手动开合、M3/M5连续开合及暂停继续。

安装处新增实际STL交集回归检查 `python -B simulator/check_mount.py`。检查用依赖为 `trimesh` 与 `manifold3d`，本机临时目录已安装。当前尺寸下检查复现旧安装约2305.685 mm³交叠，并验证修正安装在21个开合姿态、16个夹爪零件共336项腕部交集检查中均小于0.001 mm³。检查范围为夹爪与腕部支架。
