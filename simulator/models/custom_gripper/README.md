# ZCJD 夹爪照片重建模型

根据实拍照片和卷尺刻度建立参数化实体装配，原始照片保存在本地。模型包含灰色安装底座、舵机安装槽与支撑轨、扇形齿轮连杆、金属平行连杆、紫色带齿爪指和销轴，共16个装配件。

照片存在透视、遮挡和不同高度的比例误差。主要尺寸为照片估算，厚度、孔径、齿轮模数、齿数及配合间隙包含工程重建假设，制造前需要实测。参数表中的约2–2.5 mm不确定度仅用于标记估算程度，并非检定公差。

根据新安装照 IMG_20261116_163953.jpg 与用户明确的方向说明，舵机壳体在板面上的长轴沿局部X方向，与底板长边Y垂直。安装支撑轨、输出轴避让槽及固定孔同步横置，输出轴保持与左侧齿轮同轴。新增舵机壳体外形，壳体后伸深度暂取26 mm，内部齿轮与电机采用外壳包络表示。

## 模型文件

| 文件 | 内容 |
| --- | --- |
| `zcjd_gripper.step` | 70%张开姿态的彩色分件STEP装配 |
| `zcjd_gripper_closed.step` | 闭合姿态的彩色分件STEP装配 |
| `zcjd_gripper_assembly.stl` | 张开姿态装配网格，包含全部零件 |
| `parts/` | 10种局部坐标分件STL，装配时会实例化为16个零件 |
| `parameters.json` | 可编辑尺寸与照片来源说明 |
| `build_model.py` | 参数化CAD生成脚本 |
| `model.json` | 零件层级、运动关系及实体检查结果 |

STEP可导入SolidWorks、Fusion、FreeCAD等CAD软件。修改 `parameters.json` 后，在项目根目录运行以下命令重新生成模型。

```powershell
python -m pip install cadquery-ocp-novtk==8.0.1.1.0
python -B simulator/models/custom_gripper/build_model.py
```

建模依赖 `cadquery-ocp-novtk 8.0.1.1.0`。脚本从自身目录读取参数，并将 STEP、STL 和模型清单直接输出到此目录。

## 当前主要参数

| 项目 | 采用值 | 依据 |
| --- | --- | --- |
| 底板横向宽度 | 45 mm | 161000卷尺及底板轮廓估算 |
| 底板前后长度 | 50 mm | 160714、160723、160841卷尺估算 |
| 底板厚度 | 约8 mm | 170535直接测量底板侧面的近照 |
| 安装翻边总伸出 | 约21 mm | 170225近照重新读取 |
| 安装翻边厚度 | 约5 mm | 170303近照重新读取 |
| 舵机支撑肋宽 | 约6 mm | 165559卷尺近照参考 |
| 舵机支撑凸起高度 | 约17 mm | 165503中从支撑端部至底板背面的近似读数 |
| 翻边两孔中心距 | 30 mm | 160819估算，待卡尺复核 |
| 翻边孔径 | 4.2 mm | 照片比例及通孔假设 |
| 齿轮中心距 | 20 mm | 160723轴心位置估算 |
| 两平行杆间距 | 10 mm | 161000指根两孔位置估算 |
| 连杆孔距 | 25 mm | 160723与161000估算 |
| 爪指前伸长度 | 30 mm | 紫色爪指轮廓估算 |
| 爪指总厚度 | 11 mm | 侧面与底面照片估算 |
| 齿轮 | 模数1、20齿、20°压力角 | 名义渐开线扇形齿轮重建，待实测 |

照片中的齿轮、间隙和舵机花键孔缺少精确量测，初版采用圆孔及名义齿形。指尖齿距和齿深按外形近似。灰色安装底座底面保留了ZCJD刻字。

厚度参数依据新增4张卷尺照片修正，采用约±1 mm的照片读数估计。卷尺零点贴合、透视和遮挡仍有影响。底板采用8 mm后，齿轮、平行连杆及爪指装配层相对初始3 mm底板同步抬高5 mm，以保持原有运动间隙。

## 浏览器预览

已有仿真服务运行时打开 http://127.0.0.1:8767/gripper.html 。如需启动服务，在项目根目录运行 `python -B simulator/serve.py`。

预览支持开合程度、连续开合演示、分解视图、零件显隐、线框、俯视和底面视图。两侧齿轮同步反转，四连杆保持两根爪指平行。净开度约0–52.3 mm。闭合与张开过程中，夹持中心相对安装边的位置也会变化，页面显示当前估算值。

坐标原点位于底板后缘中心及底面，X为横向、Y朝指尖、Z垂直底板。这个坐标系用于夹爪独立建模。后续安装到机械臂时，需要根据真实安装面和工具中心确定固定变换。

## 已完成的检查

10种分件均通过Open CASCADE实体有效性检查，各文件包含一个正体积实体。张开和闭合STEP均已重新导入，并核对16个装配实体。开合行程内采样21种姿态，对两侧齿轮计算实体交集，重建齿轮在这些姿态下没有体积干涉。上述检查针对生成模型，实物配合、加工公差、舵机花键和承载能力尚需验证。

170225与170303近照更新了安装翻边的独立尺寸，总伸出约21 mm、厚度约5 mm，照片读数约±1 mm。该修订覆盖早期24 mm与6 mm估计。

170535侧面近照将底板厚度修订为约8 mm，覆盖先前6 mm估计。安装翻边厚度采用独立的5 mm参数。
